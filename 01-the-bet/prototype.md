# The Prototype Bet

## What I Built
*A chatbot interface to troubleshoot issue*
*Build me a web app prototype for an AI assistant product called Maintenance-Assist.

Who: Manufacturing operator performing production tasks on the plantfloor
Core task:  Help equipment error troubleshooting on the plant floor 
First screen: A chat window with prompt to enter error code
AI moment: When the operator enter an error code on the machine screen, the assistant generates troubleshooting steps 
Output: ability to get to the root cause following troubleshooting steps

Clean UI. Dark theme. One page. No login.*
